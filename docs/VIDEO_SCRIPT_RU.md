# Сценарий личной видеодемонстрации

Записать одним непрерывным роликом с собственным голосом. Рекомендованная
продолжительность задания — 10–20 минут. Следующий текст служит опорой для объяснения,
а не подтверждением того, что видео уже записано.

## 0–1 минута

«Я Suyubek Alisher, группа IT2-2306, Student ID 37773. Покажу свой проект,
Linux команды, GitHub репозиторий, Docker и Jenkins Pipeline».
Показать Suyubek_Alisher_info.txt и структуру проекта.

## 1–5 минута Linux

Использовать docs/COMMANDS_RU.md. Показать pwd, ls, cd, mkdir, touch, cp, mv, rm,
cat, head и tail на временных копиях. Найти application.log, показать ERROR/WARNING,
два ERROR и последние пять строк. Объяснить 600/644 и owner/group/others.
Запустить скрипт и объяснить проверку файла. Показать ps, ps aux и top, назвать PID,
владельца, CPU и память. Не читать длинные системные таблицы целиком.

## 5–8 минута Git и GitHub

Показать git status, identity, историю реальных коммитов, development и merge.
Показать git check-ignore и пустой git ls-files для игнорируемых файлов.
Открыть свой публичный GitHub репозиторий и объяснить связь local/remote,
разницу push/pull и цель веток.

## 8–12 минута Docker

Объяснить шесть инструкций Dockerfile. Показать image/container, docker logs,
переменные STUDENT_NAME/SURNAME/GROUP/ID, /student и управление stop/start/exec/rm.
Затем Compose up/ps/logs/down. Ручной контейнер предварительно удалить,
чтобы освободить имя и порт. При необходимости использовать команды из README.

## 12–18 минута Jenkins и полный цикл

Открыть Suyubek_Alisher_DevOps, показать GitHub URL, main и Jenkinsfile.
Внести небольшое реальное изменение, проверить, закоммитить и отправить из Ubuntu.
Нажать «Собрать сейчас». Объяснить Checkout, Build, Test, Docker Build, Docker Run.
Показать личные данные в Console Output, commit SHA, десять тестов и Finished: SUCCESS.
Показать работающий контейнер и новое сообщение приложения.

## 18–19 минута

Объяснить полный путь Linux → Git → GitHub → Jenkins → Docker.
При сбое стадии Pipeline должен остановиться с ошибкой; следующие обычные стадии
пропускаются. Показать ссылку на репозиторий и подготовленный PDF отчёт.

## Подготовка записи

На Mac: Shift+Command+5 → запись экрана → Параметры → выбрать микрофон.
Сделать короткую пробную запись и прослушать её. Увеличить шрифт терминала.
Не показывать файл Jenkins_access_PRIVATE.txt, приватный SSH ключ или пароли.
Веб камера в документе не требуется. Для сдачи нужен собственный голос студента.
